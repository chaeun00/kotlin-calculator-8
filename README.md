# kotlin-calculator-precourse


## 목표
사용자로부터 특정 규칙을 가진 문자열을 입력받아, 그 안에 포함된 숫자들의 합을 구하는 계산기를 구현한다.


### 기능 목록

-   [ O ] "덧셈할 문자열을 입력하세요."와 같은 안내 문구를 출력한다.
-   [ O ] 사용자로부터 문자열을 입력받는다.
-   [ O ] 입력받은 문자열이 비어 있거나 null일 경우 0을 결과로 출력한다.
-   [ O ] 쉼표(`,`) 또는 콜론(`:`)을 구분자로 사용해 각 숫자의 합을 구하고, 결과를 형식에 맞게 출력한다. (예: "1,2:3" -> "결과 : 6")
-   [ O ] 커스텀 구분자를 지원한다.
    -   [ O ] `//`와 `\n` 사이의 문자를 커스텀 구분자로 사용하여 계산한다. (예: `//;\n1;2;3` -> 6)
-   [ O ] 입력된 문자열에 숫자 이외의 값이나 음수가 포함된 경우 `IllegalArgumentException` 예외를 발생시킨다.
